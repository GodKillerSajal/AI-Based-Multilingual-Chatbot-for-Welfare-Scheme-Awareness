# Multilingual Welfare Scheme Assistant — Concept Draft

This repository is intended to document a multilingual assistant concept for helping people find and understand Indian welfare schemes.

## Proposed workflow

- Retrieve scheme information from MyScheme source material.
- Ask eligibility questions through a guided screener.
- Present answers in multiple Indian languages, with optional text-to-speech support.

## Implementation status

The public repository was empty during the October 2026 review. A local README describes a Gemini and Google Cloud Run implementation, but no source code or deployment evidence was located. This draft therefore does not claim that the assistant is built, deployed, or has measured response-quality or discovery-time results.

Add implementation instructions and validated results only after the code and deployment artifacts are available for review.
